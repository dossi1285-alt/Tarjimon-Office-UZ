# Tarjimon Office UZ

O‘zbek tilidagi matnlarni kirill va lotin yozuvlari o‘rtasida transliteratsiya qilish uchun Microsoft Office yo‘nalishidagi loyiha.

## Tarkib

- `TarjimonOfficeUZ.Core` — transliteratsiya yadrosi
- `TarjimonOfficeUZ.Shared` — umumiy komponentlar
- `TarjimonOfficeUZ.Word` — Word VSTO qo‘shimchasi
- `TarjimonOfficeUZ.Excel` — Excel VSTO qo‘shimchasi
- `TarjimonOfficeUZ.Tests` — testlar
- `TarjimonOfficeUZ.Setup` — installer

## GitHub import holati

Loyiha source fayllari foydalanuvchi kompyuteridan bosqichma-bosqich import qilinmoqda. `.vs`, `bin`, `obj`, `.pfx` va boshqa maxfiy/lokal build artefaktlari repositoryga kiritilmaydi.

Batafsil: `docs/PROJECT_IMPORT.md` va `docs/ARCHITECTURE.md`.
